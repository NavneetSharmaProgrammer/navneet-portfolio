## 🏗️ How I Built This Portfolio

This portfolio was engineered to be both a **technical showcase** and a **recruiter-facing product**. Here is the full stack behind it:

### Core Tech Stack

| Layer | Technology |
|-------|-----------|
| **UI Framework** | React 18 + TypeScript |
| **3D Rendering** | Three.js · React Three Fiber · React Three Drei |
| **Animation** | GSAP (ScrollSmoother, SplitText, ScrollTrigger) |
| **Component Animations** | Framer Motion |
| **Styling** | Vanilla CSS · Glassmorphism · Tailwind utility classes |
| **Physics** | React Three Cannon / Rapier |
| **Build Tool** | Vite 5 |
| **CI/CD** | GitHub Actions (auto-deploy on every push) |
| **Hosting** | GitHub Pages |

### Key Features

- 🧠 **Interactive 3D AI/ML Lifecycle Visualiser** — A custom-built neural network scene (no external 3D files) using pure Three.js geometry with animated orbiting nodes that respond to user clicks
- 🤖 **3D Character Model** — Encrypted, IndexedDB-cached GLTF character that loads instantly on return visits (80%+ speed improvement)
- ✨ **Glassmorphism UI** — Consistent frosted-glass aesthetic across all sections
- 📐 **Hover-to-Reveal Skill Cards** — Space-saving accordion layout for the "What I Do" section
- 🗂️ **Featured Projects Section** — Animated Framer Motion cards showcasing real Data Science & Backend projects
- 🎨 **GSAP Scroll Animations** — SplitText character-by-character reveal on landing, smooth scroll throughout

## 🚀 Running Locally

```bash
# Clone the repo
git clone https://github.com/NavneetSharmaProgrammer/navneet-portfolio.git
cd navneet-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build & Deploy

```bash
# Production build
npm run build

# Deployment is automated via GitHub Actions
# Any push to main → auto-deploys to GitHub Pages
```
